# Resource licensing

Every resource carries a licence, shown in its details. The library is careful about one thing: it never treats something as free to redistribute unless a licence says so.

## Imported resources

The licence is read from the package itself:

- WordPress `style.css` (`License:`);
- `LICENSE`, `LICENCE`, `COPYING` or `README` files;
- or what the source catalogue states, for example GPL-2.0-or-later for everything in the WordPress.org directories.

Recognised licences: MIT, ISC, Apache-2.0, BSD-2/3-Clause, GPL-2.0-or-later, GPL-3.0-or-later, LGPL-3.0, MPL-2.0, CC0-1.0, Unlicense, CC-BY-3.0, CC-BY-4.0 and OFL-1.1.

- **Unknown:** when no licence is found, the item is marked *Unknown*. The details say it is "not a licence to redistribute", and the import report repeats it. You can still use it in your own projects if you own it or have permission. The studio can't decide that for you.
- **Attribution:** for licences that require a notice or credit (MIT, BSD, Apache, GPL, CC-BY and OFL) the details say "keep the credit". For CC-BY packages such as HTML5 UP, that means keeping the author's credit in the footer of any site you publish with it.
- **Copyleft:** GPL themes and patterns stay GPL when you export a WordPress theme built from them.

## What the library will not do

- It never downloads from Webflow, Framer, ThemeForest, Awwwards or Codrops. Their templates are licensed for their own platforms or per purchase, and showcase sites grant no reuse. They appear under *Other sources* as inspiration only.
- It never scrapes web pages. Discovery uses three documented APIs: WordPress.org patterns, WordPress.org themes and GitHub repository search. Only https addresses on an allowlist of hosts are fetched.
- It never imports a GitHub repository that has no recognised licence. These are shown as links only.
- It never bypasses sign-ins, paywalls or download limits.
- It stores no API keys or tokens. GitHub search runs without authentication, within GitHub's public rate limit.

## Your own and purchased templates

A template you bought (for example from ThemeForest) can be imported from your own download if your licence allows editing it. The library will show its licence as *Unknown* unless the package says otherwise. The responsibility for the licence terms stays with you.
